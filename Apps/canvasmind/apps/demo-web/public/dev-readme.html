CanvasMind – Developer Console

Press ` to toggle the in-app console. Type help inside the console for a quick list.

Quick Start

  1. Open the console (`).
  2. Try a splat demo: 
    splat.demo 30000 2
  3. Load your own image/video as splats: 
    splat.image
    (Pick jpg/png/mp4/webm; it becomes a colored point cloud billboard.)

Performance Tips

  • Use quality performance for stress tests.
  • Point size in image-splats is ~0.02; denser pixels → more points.
  • Clear everything: clear.scene (also resets budgets).
  • During gizmo drag we auto-relax shadows/pixel ratio to keep FPS high.

Troubleshooting

  • “app not ready” → boot is still initializing; run the command again.
  • PLY not loading? Make sure it’s ASCII with positions (and optional colors).
  • Video splats: we sample the first frame; try a frame with clear foreground.

# SPLATS 2 WEB — 3D Open World Block Builder

Now includes a **procedural splat asset pipeline** that replaces PNG thumbnails with **Gaussian splat JSON** assets. Icons/textures are generated at runtime and can be exported as `.splat.json` packs (low/medium/high).

## Dev
```bash
npm i
npm run dev
```

Toggle splat textures in the World Menu → *Splat textures*.
